# Forest Walk

スマホのブラウザで遊べる、100m 四方の小さな森です。

**遊ぶ:** https://masaashi.github.io/forestwalk/

## 遊び方（スマホは横向き）

- 左の指: 画面の左側に触れるとスティックが出て、倒した方向へ歩きます（いっぱいに倒すと走る）
- 右の指: 画面の右側をなぞると見回せます
- ジャンプ: 右下のボタン
- 木登り: 木に近づくと出る「登る」ボタン。スティックの上下で登り下り、左右で幹のまわりを回る、ジャンプで飛び降りる
- 左上のボタンで 朝・昼・夕方・夜、右上のボタンで画質（自動・高・中・低）

パソコンでは WASD か矢印キーで歩き、スペースでジャンプ、E で木登り、マウスでなぞって見回せます。

## できるまで

Unreal Engine 5 で作っている森のプロジェクトの、簡易 Web 版です。小道・小川・池・木の置き方などの「森のルール」を C++ から JavaScript に写して、ブラウザの中で森を作っています。3D の表示には [Three.js](https://threejs.org/)（MIT ライセンス）を使っています。キャラクターは Tripo で作ったモデルです。
